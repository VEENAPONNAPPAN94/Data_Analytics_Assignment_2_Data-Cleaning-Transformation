# Data_Analytics_Assignment_2_Data-Cleaning-Transformation

This repository contains data preprocessing scripts designed to standardize, clean, and structure raw datasets for downstream analysis and reporting.

### Key Preprocessing Steps
* **Text Standardisation:** Corrected typos, standardized category naming conventions, and cleaned inconsistent capitalization across text fields.
* **Data Structuring:** Split merged fields (e.g., separating full names into distinct `First Name` and `Last Name` components using delimiters).
* **Conditional Formatting & Number formatting
* **Missing Value & Duplicates Handling:** Addressed missing entries, handled null values appropriately, and removed duplicate records to ensure data integrity.

### Tools & Technologies
* **Excel:** Conditional formatting, text-to-columns splitting, advanced formulas (`PROPER`, `TRIM`), and Find & Replace operations.
